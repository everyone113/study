# StudyMediaHub - Project Guidelines & Rules

## 1. Automatic GitHub Synchronization (Bắt Buộc)
- **Quy tắc đẩy mã nguồn tự động**: Từ nay về sau trong dự án này, mọi thay đổi, tính năng mới hoặc bản sửa lỗi sau khi hoàn tất kiểm tra đều **BẮT BUỘC** phải được commit và tự động đẩy lên GitHub (`git push origin main`).
- Đảm bảo repo luôn đồng bộ với `https://github.com/everyone113/study.git`.

## 2. Tiêu chuẩn kiến trúc
- **Backend**: FastAPI + SQLite (`backend/data/studymedia.db`).
- **Frontend**: React + Vite + Tailwind CSS (`frontend/src`).
- **Môi trường & Vị trí**: Dự án cố định tại `D:\admin\projects\StudyMediaHub` (ổ D).
