# 🎓 StudyMediaHub - Personal Student & Media Suite

**Trạm Điều Hành Cá Nhân Dành Cho Sinh Viên & Nhà Sáng Tạo Nội Dung**  
Vị trí lưu trữ: `D:\admin\projects\StudyMediaHub`

---

## 🌟 Giới Thiệu Dự Án

**StudyMediaHub** là ứng dụng tất-cả-trong-một (All-in-One Personal Workstation) hoạt động độc lập ngay trên máy tính của bạn (ổ D). Ứng dụng kết hợp hoàn hảo giữa không gian quản lý học tập đại học và một xưởng sản xuất media thông minh, hỗ trợ sử dụng mượt mà trên cả **Máy tính (PC/Laptop)** và **Điện thoại di động (iPhone/Android)**.

---

## 🚀 Các Tính Năng Chính

### 1. 📚 Quản Lý Học Tập & Điểm Số Sinh Viên
- **Quản lý môn học:** Quản lý mã môn, tên môn, số tín chỉ, giảng viên, phòng học, lịch học trong tuần.
- **Tính GPA tự động:** Nhập điểm thành phần (chuyên cần, giữa kỳ, cuối kỳ) với hệ số trọng số tùy chỉnh. Tự động quy đổi điểm hệ 10 sang hệ 4 và điểm chữ (A, B+, B, C+, C, D+, D, F) theo quy chế đào tạo tín chỉ đại học.
- **Tổng kết học lực:** Đánh giá phân loại học lực toàn khóa (Xuất sắc, Giỏi, Khá, Trung bình).

### 2. ⏰ Ghi Chú & Lịch Trình Môn Học
- Tạo ghi chú theo từng môn học kèm **ngày giờ hẹn nhắc nhở** và **deadline nộp bài tập/đồ án**.
- Phân loại theo mức độ ưu tiên (Quan trọng, Bình thường, Thấp) và thẻ nhãn (Bài tập, Thi cử, Đồ án).
- 1-click đánh dấu hoàn thành công việc.

### 3. 🌐 Kho & Công Cụ Tải Tài Liệu Trực Tuyến
- **Tải từ URL bất kỳ:** Dán link trực tiếp tài liệu trên mạng (PDF, slide giáo trình, docx, zip) để hệ thống tự động tải về lưu trữ trong ổ D.
- Quản lý tài liệu theo môn học, hỗ trợ tìm kiếm nhanh và mở/tải về máy chỉ với một click.

### 4. 💻 Phòng Lập Trình & Ôn Code (Java, C++, Python)
- **Biên dịch & chạy code trực tiếp:** Tích hợp trực tiếp với **JDK 21** có sẵn trên máy tính, C++ và Python 3.12.
- **Hỗ trợ Standard Input (stdin):** Nhập dữ liệu Scanner/cin tương tác trực tiếp.
- **Kho Cheat Sheet & Bài tập mẫu:** Cú pháp hướng đối tượng OOP (Kế thừa, Đa hình, Đóng gói), Collections, ArrayList, STL vector, Map, sắp xếp nạp sẵn 1-click vào trình soạn thảo.

### 5. 🎬 Xưởng Sáng Tạo Media & Lách Quét Trùng Lặp MXH
- **Tải Video TikTok & YouTube Sạch Logo:** Tự động loại bỏ hoàn toàn watermark/logo của TikTok và tải video YouTube chất lượng cao (hỗ trợ tách âm thanh MP3).
- **Bộ công cụ Lách Quét Trùng Lặp (Anti-Duplicate Engine):**
  - Đổi 100% mã hash MD5 và SHA-256.
  - Tẩy sạch toàn bộ Exif, GPS và siêu dữ liệu camera gốc; chèn siêu dữ liệu ngẫu nhiên.
  - Can thiệp vi mô vào video (chỉnh tốc độ 1.008x làm lệch phổ âm thanh, micro-zoom 2px chống quét đối xứng khung hình, re-encode AAC/x264) giúp đăng lên TikTok, Facebook Reels, Shorts không bị bóp tương tác hay dính quét bản quyền trùng lặp.
  - Công cụ tương tự dành cho hình ảnh.
- **Tách Nền Vật Thể AI:** Tải ảnh lên và nhận ngay file PNG trong suốt chỉ sau vài giây.

### 6. ✨ Tiện Ích Thông Minh Bổ Trợ
- **Dịch Phụ Đề Realtime Khi Xem Phim:** Nạp video và file phụ đề SRT/VTT -> Hệ thống tự động dịch song ngữ và hiển thị phụ đề chạy đồng bộ khớp từng giây dưới màn hình video.
- **Tạo Giọng Đọc AI (Edge-TTS):** Chuyển văn bản thành file âm thanh giọng đọc tiếng Việt (Hoài My, Nam Minh) hoặc tiếng Anh (Jenny) cực kỳ tự nhiên.
- **Flashcards 3D (Spaced Repetition):** Bộ thẻ nhớ lật 3D ôn nhanh từ vựng, cú pháp lập trình và thuật toán.
- **Đồng Hồ Pomodoro:** 25 phút tập trung cao độ + 5 phút nghỉ ngơi.
- **AI Tóm Tắt Slide:** Tự động rút gọn ý chính văn bản dài và tạo bộ câu hỏi tự ôn tập.

### 7. 📱 Kết Nối Điện Thoại (PC & Mobile)
- Giao diện Responsive tự động co giãn theo màn hình điện thoại, có thanh điều hướng đáy dạng ứng dụng di động.
- Trang **Kết nối Mobile** tự động tạo **Mã QR Code** lớn: chỉ cần mở Camera điện thoại quét là truy cập ngay trên cùng mạng Wi-Fi.
- Hỗ trợ cài đặt thành ứng dụng độc lập trên màn hình chính điện thoại (Progressive Web App - PWA).

## ⚡ Hướng Dẫn Khởi Động

### Cách 1: Khởi động 1-Click (Khuyên Dùng)
Chỉ cần nhấp đúp chuột vào tệp:
```
D:\admin\projects\StudyMediaHub\start_studymediahub.bat
```
Hệ thống sẽ tự động khởi động Backend, Frontend và mở ngay trình duyệt tại địa chỉ `http://localhost:5173`.

### Cách 2: Khởi động thủ công qua dòng lệnh
1. **Khởi động Backend:**
   ```bash
   cd D:\admin\projects\StudyMediaHub\backend
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
2. **Khởi động Frontend:**
   ```bash
   cd D:\admin\projects\StudyMediaHub\frontend
   npm run dev
   ```
